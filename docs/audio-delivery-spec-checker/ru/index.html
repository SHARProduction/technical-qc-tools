Проверка спецификации аудиосдачи

Проверяет заявленные стемы, каналы, частоту, битность и loudness по выбранному пресету.

Детерминированные правила
  • Use versioned presets shipped as CC-BY-4.0 fixtures.
  • Compare metadata only; never claim signal analysis.
  • Require explicit loudness units and tolerance.
Границы
