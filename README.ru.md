# technical-qc-tools

Два связанных browser-first инструмента: **Валидатор частоты кадров и таймкода и Проверка спецификации аудиосдачи**. Неизменяемые ID: `shar-pe400-w01-09`, `shar-pe400-w01-10`.

Издатель: [SHAR Production](https://sharprod.com/). `npm run check` создаёт воспроизводимую Cloudflare-ready папку `public/` и запускает тесты. Нет аналитики, аккаунтов, загрузки или хранения данных.
